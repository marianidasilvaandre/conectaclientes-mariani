## Git
um sistema que controla e registra mudanças no projeto.

## GitHub
um site onde os repositórios Git podem ser guardados e compartilhados.

## Repositório 
a pasta onde ficam os arquivos do projeto e o histórico de versões.

## gitignore
arquivo que indica quais itens o Git deve ignorar, evitando enviar arquivos temporários ou pessoais que só poluem o projeto.

## README.md
arquivo principal de apresentação de um projeto, usado para explicar do que se trata, como usar e quem participou
